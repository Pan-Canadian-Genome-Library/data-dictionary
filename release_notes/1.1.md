# Summary
- Translatable fields moved from study to study_translation
- Numerous source_term fields added. All optional
- Certain fields have had their descriptions and regex expanded to support more ontologies
- Certain fields have had their regex updated to loosen restrictions and/or address typos
- Analysis foreign key ids updated from singular to array
- New field treatment.treatment_type_other to alternative forms of treatment
- New field age_at_sociodem_collection_missing_reason to track reason why sociodem age cannot be provided
- Updates to sociodemographic.education enum list

## study

- Field study.funding_sources was removed
- Field study.keywords was removed
- Field study.participant_criteria was removed
- Field study.program_name was removed
- Field study.study_description was removed

## study_translation

- New entity study_translation created
- New Field study_translation.funding_sources created
