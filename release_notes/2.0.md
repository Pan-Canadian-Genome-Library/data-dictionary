# Summary
- Participant-level fields moved from `demographic` to `participant`. The `demographic` entity was removed
- DUO consent fields moved from `participant` to `study`. `duo_modifier` was not carried over
- Sociodemographic mappings updated from PCGL Reference Survey v1.0 to v2.0
- `Not applicable` replaced by `Missing - Not applicable` in several sociodemographic code lists
- `Another method of collection` options added to several `*_collect_method` fields
- 30 new sociodemographic fields added
- `sex_at_birth`, `sex_collect_method` and `sex_another_category` added to `participant`
- Typo and wording corrections in `procedure`, `medication`, `sample` and several sociodemographic fields
- Updates to `treatment`, `analysis` and `workflow`

## participant

- Field participant.duo_permission was removed (moved to study)
- Field participant.disease_specific_modifier was removed (moved to study)
- Field participant.duo_modifier was removed
- New Field participant.age_at_death created (moved from demographic)
- New Field participant.age_at_enrollment created (moved from demographic)
- New Field participant.cause_of_death created (moved from demographic)
- New Field participant.vital_status created (moved from demographic)
- New Field participant.sex_at_birth created
- New Field participant.sex_collect_method created
- New Field participant.sex_another_category created

## study

- New Field study.duo_permission created (moved from participant).
- New Field study.disease_specific_modifier created (moved from participant). Its description now notes the pipe delimiter

## demographic

- Entity demographic was removed and Fields demographic.age_at_death, age_at_enrollment, cause_of_death and vital_status were removed (moved to participant)

## sociodemographic

- exact_mappings updated from PCGL Reference Survey v1.0 to v2.0 on all existing fields
- sociodemographic.education's description was updated. restrictions.codeList was updated, adding "Undergraduate degree" and "Missing - Not applicable" and removing "Bachelor's degree" and "Not applicable"
- sociodemographic.education_collect_method's restrictions.codeList was updated. Adding "Administratively collected" and "Another method of collection"
- sociodemographic.ethnicity's description was updated. restrictions.codeList was updated, removing "Free text input" and "Not applicable", and adding "Missing - Not applicable" and the Statistics Canada list of Indigenous, national, and regional/cultural/religious origins
- sociodemographic.ethnicity_another_category's condition updated from "Free text input" to "Another Ethnic or Cultural Origin"
- sociodemographic.gender's description was updated. restrictions.codeList was updated, adding "Missing - Not applicable" and removing "Not applicable"
- sociodemographic.gender_collect_method's restrictions.codeList was updated. Adding "Socially assigned", "Administrative gender" and "Another method of collection", and removing "Other"
- sociodemographic.geographic_location's description was updated
- sociodemographic.geographic_location_collect_method's restrictions.codeList was updated. Adding "Another method of collection" and "Administratively collected"
- sociodemographic.personal_income's description was updated. restrictions.codeList was updated, adding "Missing - Not applicable" and removing "Not applicable". restrictions.required was removed
- sociodemographic.personal_income_collect_method's description was updated. restrictions.codeList was updated, adding "Before taxes", "After taxes" and "Missing - Not applicable" and removing "Self-identified" and "Derived". restrictions.required was removed
- sociodemographic.race's description was updated
- sociodemographic.race_collect_method's description was updated. restrictions.codeList was updated, adding "Another method of collection"
- sociodemographic.sex_at_birth's description was updated. restrictions.codeList was updated, adding "Prefer not to answer"
- sociodemographic.sex_collect_method's restrictions.codeList was updated. Adding "Socially assigned", "Legal sex" and "Another method of collection", and removing "Other"
- sociodemographic.sociodem_date_collection's description and restrictions.regex were updated. Now accepts `YYYY` only (previously `YYYY`, `YYYY-MM` or `YYYY-MM-DD`)
- New Field sociodemographic.date_of_birth created (required)
- New Field sociodemographic.date_of_birth_collection_method created (required)
- New Field sociodemographic.total_income created (required)
- New Field sociodemographic.total_income_collect_method created (required)
- New Field sociodemographic.total_income_support created (conditioned on `total_income_collect_method`: must be empty if "Missing - Unknown", "Missing - Not collected", "Missing - Not provided" or "Missing - Restricted access"; otherwise required)
- New Field sociodemographic.accommodation_type created
- New Field sociodemographic.another_accommodation_type created (conditioned on `accommodation_type` = "Another accommodation type")
- New Field sociodemographic.accommodation_duration created
- New Field sociodemographic.accommodation_number_of_occupants created
- New Field sociodemographic.household_tenure created
- New Field sociodemographic.another_household_tenure created (conditioned on `household_tenure` = "Another status of tenure")
- New Field sociodemographic.employment_status created
- New Field sociodemographic.another_employment_status created (conditioned on `employment_status` including "Another status of employment")
- New Field sociodemographic.first_language created
- New Field sociodemographic.first_language_another_language created (conditioned on `first_language` = "Another Language")
- New Field sociodemographic.knowledge_official_languages created
- New Field sociodemographic.knowledge_non_official_language created (conditioned on `knowledge_official_languages` including "Non-official language")
- New Field sociodemographic.knowledge_official_language_preference created (conditioned on `knowledge_official_languages` including "Non-official language"; restricted to "English", "French" or a "Missing - ..." value)
- New Field sociodemographic.place_of_birth created
- New Field sociodemographic.pob_outside_canada created (conditioned on `place_of_birth` = "Outside of Canada")
- New Field sociodemographic.arrival_in_canada created (conditioned on `place_of_birth` = "Outside of Canada"; restricted to "Less than 5 years", "5-9 years", "10 or more years", "Do not know", "Prefer not to answer" or a "Missing - ..." value)
- New Field sociodemographic.parent1_place_of_birth created
- New Field sociodemographic.parent1_another_pob created (conditioned on `parent1_place_of_birth` = "Outside of Canada")
- New Field sociodemographic.parent2_place_of_birth created
- New Field sociodemographic.parent2_another_pob created (conditioned on `parent2_place_of_birth` = "Outside of Canada")
- New Field sociodemographic.disability_status created
- New Field sociodemographic.religion created
- New Field sociodemographic.religion_free_text_input created (conditioned on `religion` = "Religious")
- New Field sociodemographic.sexual_orientation created
- New Field sociodemographic.transgender created
